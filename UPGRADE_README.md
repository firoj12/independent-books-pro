# Independent Books Pro

This repository contains the Independent Books project and an early authentication/sync prototype.

## Upgrade status

See `independent-books-master/UPGRADE_README.md` for the detailed implementation status, architecture notes, and limitations.

**Important:** the auth and sync service is a prototype only. It is not yet integrated with the main application database/UI, and must not be exposed to production accounting data until authorization, offline queueing, conflict handling, deployment hardening, and backup/restore are completed.
